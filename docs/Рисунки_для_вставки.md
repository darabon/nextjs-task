# Рисунки для вставки в курсовую работу

Документ: `docs/Курсовая_работа_каприз_создание_сайта.docx`. Исходная курсовая `docs/Полная_курсовая_работа_бар_все_дела.docx` не изменялась.

Все пути указаны от корня проекта `/home/stepan/Рабочий стол/nextjs`. Номера строк соответствуют текущей версии файлов. В документе в местах для скриншотов стоят пунктирные серые блоки: замените блок на изображение, подпись под ним уже пронумерована.

Рекомендации к скриншотам: снимать только код, без боковых панелей редактора; ширина изображения не меньше 1200 px; шрифт должен читаться при вставке в Word; персональные данные и токены на изображение не попадают.

## Что проверить после вставки

1. Номера рисунков идут по порядку: 1–14 в практической части, А.1–А.8 и Б.1–Б.3 в приложениях.
2. Подпись находится под изображением, а не над ним.
3. В тексте остались ссылки на рисунки 1–14; они соответствуют вставленным фрагментам.
4. После замены пунктирных блоков удалите их вместе с серым текстом «МЕСТО ДЛЯ СКРИНШОТА КОДА».
5. В Word обновите оглавление: `Ctrl+A`, затем `F9` (или «Ссылки → Обновить таблицу»).
