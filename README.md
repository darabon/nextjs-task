# каприз

Сайт парикмахерской: публичные страницы, онлайн-запись и административная панель.

## Запуск

```bash
cp .env.example .env.local
docker compose up -d
pnpm install
node --env-file=.env.local scripts/seed.mjs
pnpm dev
```

Сайт откроется на `http://localhost:3000`. MongoDB хранится в docker-volume
`kapriz-mongo-data`, поэтому данные не пропадают при перезапуске контейнера.

## Запись клиента

Аккаунты клиентам не нужны. После записи в cookie браузера сохраняется
анонимный ключ клиента. По нему страница `/book` показывает активную запись и
позволяет отменить её без звонка. На один номер телефона действует только одна
активная запись; после отмены или визита можно записаться снова.
